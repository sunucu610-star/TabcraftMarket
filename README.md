# TabCraftMarket

TabCraft için Donut SMP tarzı SHOP menüsü.

Kategoriler: End, Nether, PvP, Yemek, Kristaller.

Ana menü 27 slotluk klasik SHOP görünümündedir. Kategoriye tıklanınca ürün menüsü açılır. Sol tık satın alır, sağ tık satar; Shift ile 64 adetlik işlem yapılır.

Gereksinimler: Java 25, Paper 26.1.2, Vault ve Vault destekli ekonomi eklentisi.

Komut: /shop (alternatif: /market, /tabmarket).

Fiyatlar ve ürünler plugins/TabCraftMarket/config.yml dosyasından düzenlenir.

GitHub Actions, main dalına gönderilen değişikliklerde otomatik JAR derler. Actions > Build TabCraftMarket > Artifacts bölümünden JAR indirilebilir.
